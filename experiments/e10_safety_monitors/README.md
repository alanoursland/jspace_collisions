# Safety Monitor Stress Tests

Program family: E10 | Plan: Phase 5 | Status: not started

Test robustness of J-space monitoring for alignment auditing using benign,
controlled prompts that elicit safety-relevant latent states (evaluation
awareness, deception recognition, injection recognition). Measure
monitor_coverage and evasion_gap for token monitors vs richer monitors.

All elicitation is simulated/fictional; no harmful content is generated.

See `docs/research_program.md` for the full procedure.
