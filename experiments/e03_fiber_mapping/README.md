# Fiber Mapping

Program family: E3 | Plan: Phase 3 | Status: not started

Explore the set of activations sharing a fixed J-lens readout: nullspace
sampling under norm constraints, gradient-based behavior maximization subject
to J-distance <= epsilon, sparse perturbations preserving top-k readout.

Primary metric: fiber_behavior_variance = Var(B(h+delta) | L(h+delta) ~= L(h)).

See `docs/research_program.md` for the full procedure.
