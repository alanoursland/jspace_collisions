# Context-Specific Jacobians

Program family: E8 | Plan: Phase 6 | Status: not started

Test whether the corpus-average Jacobian hides contextual variation: fit
lenses on web text, code, math, safety transcripts, multilingual and
adversarial corpora; compare in/out-of-domain readout quality and collision
rates against the global lens.

See `docs/research_program.md` for the full procedure.
