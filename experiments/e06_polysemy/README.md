# Polysemy and Semantic Folding

Program family: E6 | Plan: Phase 4 | Status: not started

Test whether single-token directions conflate senses (bank, charge, bug,
plant, draft, proof). Compare readouts and same-token interventions across
sense contexts; test context-specific sense separation.

Success criterion: a method that predicts when token-level directions are safe
to interpret literally.

See `docs/research_program.md` for the full procedure.
