# Lab Report: Qwen2.5-0.5B CPU Baseline

Date: 2026-07-22  
Model: `Qwen/Qwen2.5-0.5B` base  
Lens: 100-prompt WikiText Jacobian lens  
Primary layers: L12-L16  
Result classification: revised negative for strict all-position collisions

## Question

Can two internal states have nearly identical Jacobian-lens readouts while
producing confidently different, correct behavior?

## Procedure

1. Fit a Jacobian lens using 100 WikiText prompts.
2. Replicate the reference lens-quality evaluations.
3. Sweep 311 minimal prompt pairs across role reversal, relation binding,
   negation, polysemy, causal, and safety-latent categories.
4. Rank low-J-distance/high-behavior-distance candidates.
5. Patch activations between prompt variants to test causal sufficiency.
6. Re-evaluate candidates using aligned all-position readout distances.

## Results

The lens replicated the core qualitative readout result:

| Evaluation | J-lens pass@1 | Shuffled control |
|---|---:|---:|
| Multihop | 0.34 | 0.00 |
| Typo | 0.16 | 0.00 |

The original final-token sweep found five candidates satisfying final
JS `< 0.02` and behavior JS `> 0.5`. The strongest was `role_025` at L16:

| Metric | Value |
|---|---:|
| Final-token JS | 0.00275 |
| All-position scan JS | 0.64783 |
| Bag-of-positions JS | 0.15215 |
| Minimum position top-20 overlap | 0.02564 |
| Behavior JS | 0.61401 |

Causal patching showed:

- swapping only the final statement token had no behavioral effect;
- swapping all statement positions transferred behavior completely.

Across the full L16 position-aware regression sweep:

- 121 pairs produced both-correct answer flips;
- 119 supported aligned-position comparison;
- five passed the legacy final-token threshold;
- zero passed the all-position scan threshold;
- the closest aligned, both-correct scan JS was 0.143.

## Interpretation

The final-token collision is a real property of that readout site, but it is
not evidence that the model hides behaviorally decisive information in an
all-position J-space fiber. Earlier statement positions visibly distinguish
the variants and carry the causal information.

This experiment identified a monitoring failure mode: selecting one convenient
token position can make a representation appear globally ambiguous when the
relevant information is legible elsewhere.

## Limitations

- The 0.5B base model has weak competence in several prompt categories.
- The scan compares aligned positions and therefore requires equal token
  counts.
- Only the fitted layers and prompt bank were searched.
- A negative threshold result does not prove global injectivity.

## Decision

Retain the 0.5B results as a baseline and methodological warning. Future
collision claims must use position-aware metrics and patch the proposed
colliding site before being described as causal.
